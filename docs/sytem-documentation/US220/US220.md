# US 220 - Generate reports on maintenance costs per aircraft or per aircraft model

## 1. Context

This User Story is part of Phase 2 (WP#4B - Enhanced Maintenance Management). To support strategic financial decisions, the ATCC (Air Transport Control Center) requires visibility into the financial impact of maintenance operations. This feature allows the generation of maintenance cost reports, aggregated either by specific aircraft or by aircraft model, providing insights into operational expenses.

## 2. Requirements

**US 220:** "As an ATCC, I want to generate reports on maintenance costs per aircraft or per aircraft model."

**Acceptance Criteria / Business Rules:**
* **Authentication & Authorization:** The user must be authenticated and have the role of `ATCC`.
* **Report Options:** The user must be able to choose the granularity of the report:
    * By `Aircraft` (total cost for a specific tail number).
    * By `Aircraft Model` (aggregated total cost for all aircraft of a specific model).
* **Calculation:** The system must sum the costs associated with all `COMPLETED` maintenance records.

## 3. Analysis

To provide accurate financial reports, the `MaintenanceRecord` entity must include a `cost` attribute. The aggregation will be performed at the database level to ensure performance. We will use two separate query strategies (or a dynamic one) to handle the two grouping levels (aircraft registration vs. model designation).

* **Controller-Service-Repository:** Standard tiered architecture.
* **Database Aggregation:** Use of `SUM()` and `GROUP BY` in JPQL to perform heavy calculations in the database.
* **DTO Projection:** Using a custom constructor in the JPQL query to map the result directly into a `CostItemDto`.

## 5. Implementation

### Key Components

1. **`MaintenanceRecordRepository`:**
    * Query for aggregation:
      ```java
      // Per Aircraft
      @Query("SELECT new isep.psoft.aisafe.application.CostItem(m.aircraft.registrationNumber, SUM(m.cost)) " +
             "FROM MaintenanceRecord m WHERE m.status = 'COMPLETED' GROUP BY m.aircraft.registrationNumber")
      List<CostItem> calculateCostsPerAircraft();

      // Per Model
      @Query("SELECT new isep.psoft.aisafe.application.CostItem(m.aircraft.model.modelName, SUM(m.cost)) " +
             "FROM MaintenanceRecord m WHERE m.status = 'COMPLETED' GROUP BY m.aircraft.model.modelName")
      List<CostItem> calculateCostsPerModel();
      ```
2. **`GenerateCostReportUseCase`:** Processes the request parameter (`type`) and invokes the corresponding repository method.
3. **`MaintenanceController`:** Exposes a `GET` endpoint at `/api/maintenance-records/reports/costs?type=...`.

## 6. Integration and Demonstration

To demonstrate this feature:
1. Ensure the system has multiple `COMPLETED` maintenance records with associated costs.
2. Authenticate as an `ATCC` user.
3. Call `GET /api/maintenance-records/reports/costs?type=AIRCRAFT` or `GET /api/maintenance-records/reports/costs?type=MODEL`.
4. The system should return `200 OK` with a summary of total costs aggregated by the chosen identifier.

## 7. Observations

* The `cost` field must be added to the `MaintenanceRecord` domain entity if not already present.
* The reports strictly include `COMPLETED` maintenance, as planned or ongoing maintenance costs might be estimates and not final expenditures.
