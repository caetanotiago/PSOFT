# US 221 - View average maintenance turnaround time per aircraft type

## 1. Context
This User Story is part of Phase 2 (WP#4B - Enhanced Maintenance Management). To support fleet maintenance planning and operational efficiency, the Maintenance Supervisor needs to monitor the average turnaround time for maintenance activities. This metric is analyzed per aircraft type (Aircraft Model) to identify which models are more demanding in terms of actual maintenance duration.

## 2. Requirements
**US 221:** "As a Maintenance Supervisor, I want to view average maintenance turnaround time per aircraft type."

**Acceptance Criteria / Business Rules:**
* **Authentication & Authorization:** The user must be authenticated and have the role of MAINTENANCE_SUPERVISOR.
* **Scope:** The calculation must strictly include completed maintenance records (records with valid CompletionNotes).
* **Definition:** "Aircraft Type" refers to the AircraftModel.
* **Calculation:** The average turnaround time is the arithmetic mean of the actual duration of completed maintenance records, grouped by their respective aircraft model.

## 3. Analysis
To calculate the true turnaround time, the system cannot rely on the 'expectedDurationMinutes' (which is merely an estimate). The actual time spent must be recorded when the maintenance is completed. Furthermore, since MaintenanceRecord and Aircraft are decoupled aggregates, the grouping by AircraftModel must be resolved via a cross-aggregate query in the database.

**Architectural Decisions:**
1. **Domain Update:** An actualDurationMinutes (Integer) attribute must be added to the CompletionNotes Value Object.
2. **Database Aggregation:** Use JPQL's AVG() function combined with an implicit JOIN between MaintenanceRecord and Aircraft to group the results by the model designation.

## 5. Implementation

### Key Components

1. **CompletionNotes (Domain Value Object):**
   Needs to be updated to include: private Integer actualDurationMinutes;

2. **MaintenanceRecordRepository:**
   Aggregation Query handling the decoupled aggregates:

   @Query("SELECT new isep.psoft.aisafe.application.TurnaroundItem(a.model.modelName, AVG(m.completionNotes.actualDurationMinutes)) " +
   "FROM MaintenanceRecord m, Aircraft a " +
   "WHERE m.aircraftRegistration = a.registrationNumber.registrationNumber " +
   "AND m.completionNotes IS NOT NULL " +
   "GROUP BY a.model.modelName")
   List<TurnaroundItem> findAverageTurnaroundTimePerModel();

3. **ViewAvgTurnaroundTimeUseCase:** Calls the repository and prepares the TurnaroundReportDto.

4. **MaintenanceController:** Exposes the GET endpoint at /api/maintenance-records/reports/turnaround-time.

## 6. Integration and Demonstration
To demonstrate this feature:
1. Ensure multiple maintenance records exist with CompletionNotes holding varying actual durations for different aircraft models.
2. Authenticate as a MAINTENANCE_SUPERVISOR.
3. Call GET /api/maintenance-records/reports/turnaround-time.
4. The system should return 200 OK with a list showing each model name and its true average maintenance time.

## 7. Observations
* The query explicitly filters for m.completionNotes IS NOT NULL to guarantee that only actually completed operations influence the average turnaround time.
* Adding actualDurationMinutes to CompletionNotes ensures the historical immutability of the maintenance operation's true cost and time.
